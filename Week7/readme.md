## 📚 Core Fundamentals

---

### 🚀 DevOps
**DevOps** is a set of practices, cultural philosophies, and tools that combines Software Development (**Dev**) and IT Operations (**Ops**). Its goal is to shorten the systems development life cycle and provide continuous delivery with high software quality.

* **Continuous Integration & Continuous Delivery (CI/CD):** Automating the build, testing, and deployment pipelines.
* **Infrastructure as Code (IaC):** Managing and provisioning infrastructure through code/configuration files rather than manual processes.
* **Monitoring & Observability:** Tracking application performance and system health in real-time.

---

### 🐳 Docker
**Docker** is an open-source platform designed to make it easier to create, deploy, and run applications by using **containers**. Containers allow a developer to package up an application with all of the parts it needs (libraries, dependencies) and ship it all out as one package.

* **Image:** A read-only template that contains the application source code, libraries, and tools needed to run an application.
* **Container:** A runnable, isolated instance created from a Docker image.
* **Dockerfile:** A text script containing commands used to assemble a Docker image.
* **Docker Compose:** A tool for defining and running multi-container Docker applications.

---

### 🤖 Generative AI (GenAI)
**Generative AI** is a branch of Artificial Intelligence focused on creating new content—such as text, images, audio, code, or synthetic data—based on patterns learned from existing data.

* **Large Language Models (LLMs):** Deep learning algorithms trained on massive datasets to understand and generate human-like text and code.
* **Prompt Engineering:** The technique of structuring text inputs to effectively communicate with and retrieve optimal outputs from AI models.
* **Retrieval-Augmented Generation (RAG):** Enhancing LLM responses by connecting them to external, specialized knowledge bases or database systems.
