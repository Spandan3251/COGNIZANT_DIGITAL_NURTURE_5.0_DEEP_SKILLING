# 🚀 Cognizant Digital Nurture 5.0 - Deep Skilling (.NET FSE)

Welcome to my central repository for the **Cognizant .NET Full Stack Engineer (FSE)** training program. This repository documents my learning journey, hands-on lab exercises, and assignments completed over the span of 7 weeks.

---

## 📌 Program Overview
* **Batch:** .NET FSE (Angular)
* **Domain:** Full Stack Web Development
* **Key Tech Stack:** .NET 8, C#, Entity Framework Core, ASP.NET Core Web API, Angular, Git, DevOps, Docker & GenAI

---

## 🗓️ 7-Week Training Syllabus & Progress

### 📍 Week 1: Core Fundamentals & Testing
* **Design Patterns & Principles:** Understanding SOLID principles and common software design patterns.
* **Data Structures & Algorithms:** Key concepts for problem-solving and code optimization.
* **Advanced SQL:** Complex queries, stored procedures, indexing, and database optimizations.
* **Unit Testing:** Basics of unit testing and mocking using **NUnit** and **Moq**.

---

### 📍 Week 2: Data Access & Web API Basics
* **Entity Framework Core 8.0:** ORM mapping, Code-First migrations, DbContext setup, and database interactions.
* **ASP.NET Core 8.0 Web API:** Creating RESTful APIs, routing, controllers, and dependency injection.

---

### 📍 Week 3: Advanced Web API Development
* **ASP.NET Core 8.0 Web API:** Implementing advanced REST practices, custom middleware, DTOs, data validation, and error handling.

---

### 📍 Week 4: Architecture & Microservices
* **Microservices Architecture:** Monolith vs. Microservices, service decomposition, synchronous/asynchronous communication, and API gateways.

---

### 📍 Week 5: Frontend Development (Angular)
* **Angular Basics & Architecture:** Components, Templates, Modules, Services, and RxJS Observables.
* **State & Routing:** Angular Router, Forms (Template-Driven & Reactive), HTTP Client module integration.

---

### 📍 Week 6: Modern Web & Version Control
* **Angular Deep Dive:** Advanced component communication, directives, custom pipes, and state management.
* **Version Control System (Git):** Branching strategies, repository management, resolving merge conflicts.
* **Continuous Integration & Delivery:** Introduction to CI/CD pipelines.

---

### 📍 Week 7: DevOps, Containerization & Modern AI
* **DevOps:** Overview of DevOps lifecycle, CI/CD automation, and infrastructure concepts.
* **Docker:** Containerizing applications, writing `Dockerfile`, running single/multi-container applications.
* **Generative AI Fundamentals:** Basics of GenAI, Large Language Models (LLMs), Prompt Engineering, and modern AI integration concepts.
